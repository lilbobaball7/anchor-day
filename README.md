# Anchor Day

Jackie’s editable daily and weekly planner. It includes Today, Week, Lists, Home, and History pages in one `index.html` file.

## Saving

Entries save automatically in the browser on the device being used. They do not automatically sync between devices. Use **Home → Download backup** before changing browsers/devices, and **Import backup** to restore it.

## Updating GitHub Pages

In the GitHub repository, choose **Add file → Upload files**. Upload `index.html` and `README.md`, allow them to replace the existing files, and commit the changes. GitHub Pages may take a minute or two to update.
